# Algeriom

A minimal desktop browser for Algeria, built with Electron. Tabs use real
browser views (not iframes), so sites that block embedding elsewhere (like
Google or Facebook) load normally here.

## Get an installer without a computer (GitHub Actions)

1. Create a new GitHub repo and upload this whole folder to it.
2. Go to the repo's Actions tab and enable workflows if prompted.
3. Push to `main` (or open "Build Algeriom" and hit "Run workflow").
4. Wait for the three build jobs to finish.
5. Open the run, scroll to Artifacts, download the one for your OS.
